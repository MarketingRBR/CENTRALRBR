# Central RBR — publicação no GitHub Pages
Envie para o repositório SOMENTE os arquivos desta pasta: index.html, .nojekyll e robots.txt.
O index.html contém o aplicativo criptografado; sem a senha, nomes, CPFs, estoques e indicadores não aparecem no código.
NÃO envie o código-fonte (pasta src/, planilhas em src/data/raw/) para um repositório público.
Para atualizar: gere de novo com `node build-pages.mjs` e substitua o index.html no repositório.
