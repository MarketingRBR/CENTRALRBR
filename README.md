# Central RBR

Portal interno dos promotores da RBR Representações.

**Acesso:** https://marketingrbr.github.io/CENTRAL/ (entrar com CPF e senha).

Este repositório contém apenas a versão publicada da Central. O `index.html` é criptografado:
sem a senha, o código não mostra nomes, CPFs, estoques ou indicadores.

O código-fonte e as planilhas ficam no projeto de manutenção (não publicar em repositório público).
Para atualizar a Central, substitua o `index.html` pela versão nova gerada com `node build-pages.mjs`.
